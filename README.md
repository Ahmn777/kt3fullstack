# КТ 3 — Адаптивная стилизация Tailwind CSS

Готовый учебный React-проект по заданию КТ 3:
- адаптивная сетка: 1 колонка на телефоне, 2 на планшете, 3 на широком экране;
- читаемая форма создания записи;
- кнопка с `hover` и `disabled`;
- адаптивная шапка сайта;
- стандартные классы Tailwind CSS.

## Как запустить в VS Code

1. Скачайте ZIP и распакуйте его.
2. Откройте в VS Code папку `kt3-tailwind-project` (именно папку, где находится `package.json`).
3. Откройте Terminal → New Terminal.
4. Выполните:

   ```bash
   npm install
   npm start
   ```

5. Дождитесь открытия сайта в браузере. Если браузер не открылся автоматически, перейдите на `http://localhost:3000`.

## Проверка
- Уменьшите ширину браузера: карточки должны стать в одну колонку.
- На ширине планшета карточки располагаются по две, на большом экране — по три.
- Заполните название и описание в форме, затем нажмите «Добавить запись».
- Пока обязательные поля не заполнены, кнопка отключена; при наведении её цвет меняется.

## Важно
Это самостоятельный демонстрационный frontend для практики по приложенному заданию. Он не подключён к серверу и не реализует настоящую авторизацию или сохранение в базе данных. Если преподаватель требует стилизовать именно ваше Fullstack-приложение из тем 3.1–3.2, нужно будет перенести классы Tailwind в его компоненты.
